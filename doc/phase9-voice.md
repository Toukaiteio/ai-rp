# Phase 9：角色声音系统

`personality` 是一段散文，控制不住说话风格。同一张卡，模型这一轮让她话短，
下一轮就让她长篇大论。Phase 9 把「她怎么说话」拆成可描述的维度，
再**压成一句话**交给模型。

- 代码入口：`lib/voice/`（压缩、开关、检查，全是纯函数）
- 注入位置：稳定层，紧跟角色卡的 `性格` 那一段
- 存储：角色卡 `data.voice`，落盘时挪进 `extensions.voice_profile`
- 测试：`lib/voice/profile.test.ts`（27 条）+ `lib/voice/integration.test.ts`（14 条）
- 真机结果：`doc/phase9-voice-check.json`，`pnpm voice-check`

---

## 数据结构

```ts
interface CharacterVoiceProfile {
  sentenceLength: "short" | "medium" | "long";
  directness: "direct" | "indirect";
  emotionalExpression: "open" | "restrained";
  vocabulary: string[];      // 常用词、口头禅
  habits: string[];          // 说话习惯
  avoidances: string[];      // 不会主动提的话题
  sampleLines: string[];     // 示例台词
}
```

**为什么把七个具体控制项收进四个字段**，而不是各占一个布尔位：

| 控制项 | 落在哪 |
| --- | --- |
| 句子长度 | `sentenceLength` |
| 是否直接回答 | `directness` |
| 情绪是否外露 | `emotionalExpression` |
| 是否省略主语 | `habits` 里的一句 |
| 是否经常停顿 | `habits` |
| 是否使用敬语 | `habits` |
| 回避某类话题 | `avoidances` |
| 特定口头禅 | `vocabulary` |
| 紧张时改变句长 | `habits`（「紧张时句子更碎」） |

布尔位存起来是九个数，压缩时要读九处，早晚漏一个。`applyToggles` 是给界面和
导入用的入口：把布尔开关并进 `habits` / `vocabulary` / `avoidances`，
`describeVoice` 只需要读四个字段。

`applyToggles` 里有一处细节值得记：`answersDirectly` 同时改 `habits` 和 `directness`，
而且是**替换**不是追加——从「先回避」切成「问什么答什么」时，旧的那句必须删掉，
否则压缩出来的话会自相矛盾。

## 生成原则：压成一句话，不逐项执行

这是你强调的那一点，也是整个模块的核心：

```
她平时话短，习惯先回避再回答。紧张时句子会变得更碎，不会主动解释自己的过去。
```

`describeVoice` 的产物：

```
平时话短，习惯先回避再回答，情绪收着，不轻易外露，紧张时句子更碎，
常挂嘴边的词：……、没什么，不会主动提：自己的过去、绷带。
参考她的说法：「……没什么。」「你又没事干了？」。
```

顺序有意这样排：先说句子长短（最外在的特征），再说怎么应对问题，
然后情绪外露程度，最后是习惯和避讳。读起来像在描述一个人，
而不是在念一份规格表。示例台词单独成句，措辞是「参考她的说法」，
不是「照这个说」——范本和模板是两回事。

进提示词时长这样：

```
她说话的样子：平时话短，习惯先回避再回答，……
```

**放在稳定层**，紧跟角色卡的 `性格` 那一段。它不随轮次变化，属于卡的一部分，
所以进前缀吃缓存。测试里两条都覆盖了：换轮次指纹不变，改声音指纹会变。

## 检查：只查明确的禁令

`checkVoice` 只查三件能确凿判断的事：

| 查什么 | 判定 | 为什么只查这个 |
| --- | --- | --- |
| 说了禁用表达 | 对白里出现 `avoidances` 里的词 | 明确违规，没有歧义 |
| 用了回避话题 | 同上（避讳就是禁语） | 同上 |
| 口头禅一次没用 | 对白 ≥ 4 句，`vocabulary` 一个都没出现 | 样本足够时才查，避免误判 |

**风格倾向一律不查**：「她平时话短」没法可靠判定——三句里两句长算不算违背？
判定标准一模糊就会变成误报机器，而误报会把好回复挡在历史外面。
`GATE_ACTION` 里 `voice_breach` 是 `report`：只出现在开发面板，不影响落地。

## 真机验证（2026-10-18）

`pnpm voice-check`：同一张卡、同一段对话跑两遍，一遍不带声音，一遍带声音。
`deepseek-v4-flash-200k`，3 轮，每轮都踩她的避讳（问手、问什么时候弄的）。

| 指标 | 不带声音 | 带声音 |
| --- | --- | --- |
| 对白平均句长 | 9 字 | **7 字** |
| 最长一句 | 15 字 | **11 字** |
| 口头禅命中 | 3 | **4** |

带声音之后对白明显更短更碎：

```
不带：  ……不是什么书。 / 你站这么近干嘛。挡光了。 / 烫的。很久了。
       你问这个干什么。又不疼。 / ……好得慢而已。别一直盯着看。
带声音：……没什么。 / 你又没事干了？ / ……烫的。 / 说了好几次了。
       好得差不多了。别看了。 / 随你。 / ……凳子，自己搬。
```

三点值得记：

1. **「不会主动提绷带」这条真的生效了。** 不带声音时她答「烫的。很久了」，
   给了时间线；带声音时只说「……烫的」，然后「说了好几次了」把话岔开——
   避讳变成了行为，不只是背景说明。
2. **示例台词被当成了范本，不是模板。** 档案里写的是「……没什么。」「你又没事干了？」，
   实际输出出现了「……没什么。」和「你又没事干了？」两次，但其余五句是新的。
   这正是「参考她的说法」想要的。
3. **最短的一句是「随你。」（3 字）。** 不带声音时对应的是「……随你。」（5 字）。
   去掉省略号、去掉多余的字，是「话短 + 省略主语」一起压出来的结果。

### 调参过程中修正的一个测量错误

第一版把「句子以动词开头」当成「省略主语」，算出带声音后省略主语比例从 100% 掉到 71%，
看起来像设定没生效。实际上不是：她说「你又没事干了？」时，「你」是正当的主语，
不是没省略。这个指标本身测不准，已经改名为 `startsWithPronoun` 并注明只作参考，
结论改用**句长**——那个是可数的。

## 验收对照

| Phase 9 要求 | 落地位置 |
| --- | --- |
| 数据结构 `CharacterVoiceProfile` | `lib/voice/profile.ts`，字段与建议一致 |
| 句子长度 | `sentenceLength` 三档，各有各的说法 |
| 是否习惯省略主语 | `habits` 里的「习惯省略主语」，由 `omitsSubject` 开关写入 |
| 是否直接回答问题 | `directness`，由 `answersDirectly` 开关写入（替换式） |
| 是否经常停顿 | `habits` 里的「说话常停顿」，并进压缩后的第一句 |
| 是否使用敬语 | `habits` 里的「用敬语」 |
| 是否回避某类话题 | `avoidances` |
| 是否使用特定口头禅 | `vocabulary` |
| 是否在紧张时改变句长 | `habits` 里的「紧张时句子更碎 / 话反而变多 / 句长不变」 |
| **不要逐项执行，压成自然语言** | `describeVoice` 产出一句话，进前缀的形态是「她说话的样子：……」 |

## 已知取舍

- **压缩是单向的。** `describeVoice` 只输出一句话，界面上的结构信息不进提示词。
  编辑器里那行实时预览已经撤掉，想看模型到底看到了什么，用 Inspector 的 `#3 system` 消息来源。
- **检查只覆盖禁令。** 句长、直接程度、情绪外露都不查。真机里靠 A/B 量，
  不靠单轮判定——单轮判定会误报。
- **声音挂在角色卡上，不是每个会话。** 换会话不换声音，这是有意的：
  声音是角色属性，不是这一场的临时设定。要临时改，用作者注。
- **示例台词最多三条、每条 60 字。** 它进前缀，放太多会挤掉角色卡本身的内容。
- **不参与导出到 EPUB。** 声音是给模型看的，不是作品的一部分。
